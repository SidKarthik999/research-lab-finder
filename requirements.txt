# environment.yml stays the source of truth for local dev (conda + pip), but

# backend/google_auth.py imports google.auth.transport.requests, which
# needs it directly. Its own transitive deps (urllib3, idna, certifi,
# charset-normalizer) are pulled in automatically by pip, no need to pin
